# ROAH Reference Materials

このフォルダは、那覇空港レイアウト開発の参考資料を保管する場所です。

## Files

- `JP-AD-2.24.1-ROAH-en-JP.pdf`
  - 那覇空港 Aerodrome Chart 1。
  - 滑走路、誘導路、エプロン、ターミナル、管制塔、水域、空港島構造を読み取るための開発参考資料として使用します。

## Usage Policy

- このPDFは、Unity内の画像素材、テクスチャ、背景画像として使用しません。
- PDFをScene、Prefab、Material、Texture、Spriteとして取り込まないでください。
- Googleマップ画像やPDF画像をUnity内に貼り付ける代わりに、資料から読み取った配置関係をPrimitiveベースのブロックアウトへ反映します。
- 完全な実寸再現ではなく、ゲーム用に簡略化した那覇空港風レイアウトの参考として扱います。
