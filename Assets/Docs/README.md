# ATCJourneyJapan Prototype Notes

このフォルダはUnityプロジェクト内から参照しやすい開発メモ置き場です。

現在の詳細なセットアップ手順、操作方法、主要スクリプトの役割、今後のB滑走路・別空港追加方針は、リポジトリ直下の `README.md` を参照してください。

今回の実装は `Assets/Scenes/SampleScene.unity` をそのまま使い、Play開始時に `GameBootstrapper` が空港・航空機・UIを生成します。

## 今後の設計メモ

- Phase 1.15: 航空機移動経路を滑走路・誘導路・ゲートに沿うよう自然化し、一時停止型チュートリアルを導入する
- Phase 1.7: ボタン押下後に、実際の管制文を短く表示してから機体が動く演出を追加する
- Phase 2.3: 飛行機を直接クリックする方式から、到着機・出発機のフライトストリップをクリックして選択する方式へ移行する
- Phase 2.5: 接近中の到着機を把握するための簡易レーダー画面を追加する
- 将来的には、日本語表示、英語表示、日英併記表示を設定で切り替えられるようにする

## Phase 1.15 チュートリアル方針

Phase 1.15では、初心者が迷わず操作できるように、説明を一度に出す方式から一時停止型チュートリアルへ移行します。

- 初心者向けチュートリアルでは、1回に1概念だけ説明する
- 滑走路1本1機ルール、着陸許可、滑走路離脱、ゲート誘導を段階的に教える
- 説明中はゲーム進行を止め、「次へ」ボタンで進める
- 操作段階では、対象の航空機や指示ボタンに注目させてから操作させる
- Pushback、Hold Short、Contact Ground、Contact Tower、Contact Departure、フライトストリップ、レーダー/ミニマップ、空港俯瞰ビュー、経路プレビュー、スコアランク制、英語音声は後続Phaseで扱う

## 将来のUI方針

現在の右側固定の指示欄は、Phase 1用の暫定UIです。
将来的には、既存の航空管制ゲームに近い形で、左側に到着 `ARRIVAL` と出発 `DEPARTURE` のフライトストリップを配置し、そこを操作の中心にします。

- 航空機を直接クリックする方式から、フライトストリップの便名帯をクリックして選択する方式へ移行する
- 到着機と出発機は別欄で管理する
- 各ストリップには、便名、機種、使用滑走路、ゲート/スポット、現在状態、担当管制ポジションを表示する
- 選択したストリップの近くに、その機体に出せる指示ボタンを表示する
- 下部には将来的に、管制官の指示文とパイロットの復唱ログを表示する
- 右上には将来的に、簡易レーダー/ミニマップを表示する

Phase 1.1では、フライトストリップ本実装、レーダー/ミニマップ、空港俯瞰ビューはまだ追加しません。
