# ATCJourneyJapan Prototype Notes

このフォルダはUnityプロジェクト内から参照しやすい開発メモ置き場です。

現在の詳細なセットアップ手順、操作方法、主要スクリプトの役割、今後のB滑走路・別空港追加方針は、リポジトリ直下の `README.md` を参照してください。

今回の実装は `Assets/Scenes/SampleScene.unity` をそのまま使い、Play開始時に `GameBootstrapper` が空港・航空機・UIを生成します。
